## Недостающие или требующие улучшения компоненты

### 1. Отображение прогресса перебора (❌ Не реализовано)
**Проблема:** Автоматический перебор 403 кварталов занимает 5–10 минут и полностью блокирует интерфейс без визуальной обратной связи.

**Текущее состояние:**
- Код перебора: `auto_placement.py:64-98`
- Вызов в UI: `app.py:144-146`
- Нет визуального прогресс-бара

**Рекомендация:** Добавить прогресс-бар Streamlit:
```python
progress_bar = st.progress(0)
for i, block_id in enumerate(all_block_ids):
    progress_bar.progress((i + 1) / len(all_block_ids))
```

---

### 2. Карточка выбранного квартала (❌ Не реализовано)
**Проблема:** Нет отдельного UI-компонента, который показывает детальную информацию о конкретном квартале.

**Текущее состояние:**
- Таблица деталей по всем кварталам: `app.py:363-385`
- Тултипы на карте: `map_utils.py:90-111`
- Нет выделенной карточки для выбранного квартала

**Рекомендация:** Добавить компонент с:
- ID квартала
- Население
- Потребность
- Текущая вместимость школ
- Добавленная вместимость
- Остаточный дефицит
- Обеспеченность (strong/weak)
- Время в пути до ближайших школ

---

### 3. Управление сохранёнными сценариями (⚠️ Реализовано частично)
**Проблема:** Сценарии автоматически сохраняются в `st.session_state.scenarios`, но нет явного UI для добавления/удаления сценариев.

**Текущее состояние:**
- Автосохранение: `app.py:416-417` (ручной выбор)
- Автосохранение: `app.py:453-456` (автоматический подбор)
- Отображение: `app.py:198-230` (таблица сравнения)

**Рекомендация:** Добавить явные кнопки:
- "Добавить текущий сценарий к сравнению"
- "Очистить все сценарии"
- "Удалить последний сценарий"

---

### 4. Отмена долгих расчётов (❌ Не реализовано)
**Проблема:** Нет возможности прервать автоматический перебор после нажатия кнопки.

**Текущее состояние:**
- Перебор блокируется в цикле `for i, block_id in enumerate(all_block_ids)`
- Нет обработки прерывания

**Рекомендация:** Добавить кнопку "Отменить" и проверку `if stop_requested: break` в цикле.

## Заключение

Приложение `school-placement` в текущем состоянии **полностью функционально для основного сценария использования**: оценка обеспеченности при ручном размещении школ и автоматический поиск оптимального квартала.

Основная функциональность реализована и протестирована:
- ✅ Загрузка данных из практики 2
- ✅ Расчёт обеспеченности методом competitive_provision
- ✅ Интерактивная карта с цветовой визуализацией
- ✅ Ручной выбор одной или двух школ
- ✅ Автоматический перебор всех кварталов
- ✅ Сравнение сценариев
- ✅ Экспорт результатов в CSV

**Недостающие компоненты** в основном связаны с **UX-оптимизациями**, а не с отсутствием базовой функциональности:
- Прогресс-бар для перебора
- Карточка квартала
- Явное управление сценариями
- Отмена расчётов

Рекомендуется внедрить эти компоненты для улучшения пользовательского опыта, но они не являются критическими для выполнения основного функционального требования приложения.
