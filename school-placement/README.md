# Интерактивное приложение для оценки вариантов размещения школ

Приложение для оценки обеспеченности населения местами в общеобразовательных организациях (школах) при различных вариантах размещения новых школ по кварталам города Арзамас.

## Назначение

Приложение позволяет:

- Просматривать исходное состояние обеспеченности школами по кварталам
- Выбирать кварталы для ручного размещения школ и задавать их вместимость
- Рассчитывать обеспеченность для произвольных сценариев размещения
- Автоматически определять оптимальный квартал для размещения школы
- Сравнивать варианты размещения: одна школа на 600 мест, две школы по 300 мест, автоматический подбор
- Выгружать результаты расчётов в CSV

## Установка

### Требования

- Python 3.10+
- Проект `python-package-boilerplate` должен находиться в той же родительской папке (для доступа к данным)

### Шаги

1. Перейдите в папку `school-placement`:

```bash
cd school-placement
```

2. Создайте виртуальное окружение (если не создано):

```bash
python -m venv .venv
```

3. Активируйте окружение:

```bash
# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Windows (cmd)
.venv\Scripts\activate.bat

# Linux/macOS
source .venv/bin/activate
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501

## Использование

### Ручной выбор кварталов

1. Откройте вкладку **Ручной выбор**
2. Выберите сценарий: одна школа или две школы
3. Укажите ID квартала и вместимость школы
4. Нажмите **Рассчитать сценарий**
5. Просмотрите результаты: показатели, таблица, карта

### Автоматический подбор

1. Откройте вкладку **Автоматический подбор**
2. Укажите вместимость новой школы (по умолчанию 600 мест)
3. Нажмите **Разместить автоматически**
4. Дождитесь завершения перебора (может занять 5–10 минут)
5. Просмотрите рейтинг кварталов и лучший вариант на карте

### Сравнение сценариев

Вкладка **Сравнение** показывает таблицу всех рассчитанных сценариев с возможностью выгрузки в CSV.

## Методика расчёта

Используется метод **конкурентного распределения спроса** (`competitive_provision`) из библиотеки BlocksNet 1.0.0a9:

1. **Потребность** в местах рассчитывается как `население × 120 / 1000` (120 мест на 1000 жителей)
2. **Доступность** — 15 минут на автомобиле (порог времени в пути)
3. Школы **конкурируют** за спрос: распределение моделируется задачей линейного программирования (LP), где спрос направляется к ближайшим доступным школам
4. **Обеспеченность (strong)** — доля спроса, удовлетворённого в пределах 15 минут
5. **Обеспеченность (weak)** — доля спроса, удовлетворённого без ограничения времени

### Данные

- Город: Арзамас, Нижегородская область
- Кварталы: 403
- Население: 85 933 чел.
- Школы: 17, 4 250 мест
- Дефицит: 6 199 мест (59%)
- Источник: python-package-boilerplate/examples/data/arzamas/

### Допущения

- Потребность в местах: 120 мест на 1000 жителей (норматив BlocksNet)
- Доступность: 15 минут на автомобиле (порог)
- Размещение школы увеличивает суммарную вместимость школ соответствующего квартала
- Выбор земельного участка требует отдельного градостроительного обоснования
